# redeemship.com – Twitch / Kick & Discord Bot

Dieser Bot wurde speziell für [redeemship.com](https://redeemship.com) entwickelt und wird hier aus Transparenzgründen öffentlich bereitgestellt.

---

## ⚠️ Wichtiger Hinweis

Dieser Bot ist **ausschließlich für redeemship.com entwickelt** und funktioniert nur in Verbindung mit dem redeemship.com-Backend. Eine eigenständige Installation ohne Zugang zum redeemship.com-Backend ist **nicht möglich**.

Der Code wird hier veröffentlicht, damit unsere Community nachvollziehen kann, wie der Bot funktioniert.

---

## 🔧 Funktionen

- **Twitch & Kick** – Integration für Channel-Events, Rewards und Chat-Interaktionen
- **Discord** – Benachrichtigungen, Bot-Befehle und Community-Features
- Vollständig verbunden mit dem redeemship.com-Backend

---

## 📋 Voraussetzungen

- Zugang zum redeemship.com-Backend (nur intern verfügbar)
- Twitch- und/oder Kick-Entwicklerzugang
- Discord Bot Token
